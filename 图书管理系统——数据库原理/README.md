# 🏠 房屋租赁管理系统 (House Rental Management System)

> **课程名称**：数据库系统原理   
> **架构模式**：Spring Boot + Vue 3 前后端分离架构  
> **核心目标**：通过规范化的数据库设计，解决传统租房过程中信息不对称、管理效率低等问题 。

---

## 📖 项目简介
[cite_start]本项目是一个全栈式房屋租赁管理平台，旨在为房东、租客及管理员提供高效的数字化交互环境 [cite: 1][cite_start]。系统严格遵循数据库设计规范，从需求调研出发，完成了从 E-R 模型到物理表结构的转化，并依托三层架构实现了租赁业务的全流程闭环管理 。

---

## ✨ 核心功能模块

系统划分为 **后台管理端** 与 **用户前端**，支持精细化的角色权限控制：

* **👤 用户端 (租客/房东)**
  * [cite_start]**房源浏览与搜索**：支持根据区域、租金、户型等条件进行多维度筛选 。
  * [cite_start]**租赁申请**：用户可在线发起租房申请，管理个人租赁订单与合同 。
  * [cite_start]**个人中心**：维护个人基本信息、查看历史借阅记录与个人收藏 。
* **👨‍💼 管理员端**
  * [cite_start]**用户与权限管理**：维护用户信息，通过 RBAC 机制分配管理员、普通用户等权限 。
  * [cite_start]**房源审核与维护**：审核房东发布的房源信息，确保信息的真实有效性 。
  * [cite_start]**订单与合同管理**：集中管理全系统的租赁记录，生成业务报表，处理异常订单 。

## 🛠️ 技术栈与系统架构

### 后端技术 (Spring Boot)
* [cite_start]**核心框架**：Spring Boot 2.7.x，简化配置并提供稳健的业务运行环境 。
* [cite_start]**数据持久层**：MyBatis-Plus，实现高效的 ORM 映射与自动化的 CRUD 操作 。
* [cite_start]**安全验证**：集成字符校验与 SQL 注入拦截，保障数据访问安全性 。

### 前端技术 (Vue 3)
* [cite_start]**交互框架**：Vue 3 (Composition API)，提供响应式的数据绑定与组件化开发 。
* [cite_start]**UI 组件库**：Element Plus，构建简洁、专业的管理台界面 。
* [cite_start]**网络请求**：Axios 封装，实现与 RESTful API 的高效异步通信 。

### 数据库层 (MySQL)
* [cite_start]采用关系型数据库 MySQL 存储核心业务数据，通过外键约束与触发器保障数据的一致性与完整性 。

## 🗄️ 数据库设计 (Schema)

[cite_start]系统基于 6 张核心数据表构建，完整支撑了租赁业务逻辑 ：

1. **`user` (用户表)**：存储用户基础信息、加密密码及角色类型。
2. **`house` (房源信息表)**：记录房源位置、租金、图片描述、设施情况及出租状态。
3. **`order` (租赁订单表)**：记录租客、房源、租期起止、租金总额等动态业务数据。
4. **`notice` (公告表)**：由管理员发布，用于向用户推送系统规则与租赁通知。
5. **`category` (房源分类表)**：对公寓、普通住宅、商铺等不同房源类型进行分类管理。
6. **`favorite` (收藏表)**：实现用户对心仪房源的快速保存与对比。

## 🚀 系统亮点

1. [cite_start]**三层架构设计**：项目遵循 `Controller-Service-Mapper` 分层思想，显著提升了代码的复用性与可维护性 。
2. [cite_start]**E-R 模型深度建模**：科学设计多对多关系（如用户与房源的收藏关系），并将其转换为满足三范式的逻辑结构 。
3. [cite_start]**安全防御机制**：内置非法字符过滤，防止非法 SQL 攻击，通过黑名单表记录恶意操作行为 。
4. [cite_start]**响应式 UI**：基于现代前端框架，实现了在 PC 端与移动端的良好视觉兼容性 。
