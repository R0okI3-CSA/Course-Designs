# 🔐 用户密码管理系统 (User Password Management System)

> **课程名称**：JAVA程序设计
> **架构模式**：Spring Boot + Vue 3 前后端分离三层架构  

---

## 📖 项目简介
本项目是一个基于前后端分离架构构建的用户密码管理平台，旨在安全、高效地解决用户密码存储与托管问题。系统采用后端提供标准化 RESTful API 接口、前端独立部署的协作模式。核心业务涵盖多用户的全周期认证管理、个人密码凭证的安全托管以及基于黑名单的主动防御安全机制。

---

## ✨ 核心功能模块

* **👥 用户模块 (User Module)**
  * 支持用户注册与登录流程的全周期管理。
  * 登录与注册接口集成严格的字符校验，自动过滤除大小写字母、数字和下划线之外的特殊符号。
  * 基于用户角色的访问控制，实现不同角色的操作权限隔离。

* **🔑 密码托管管理 (Sensor Management)**
  * 存储用户私人的密码凭证信息，字段对应密码编号、用户名、密码、安全级别、日期与备注。
  * 借助 `user_sensor` 关联表实现多对多映射，确保用户登录后仅能查看和操作属于自己的密码记录。

* **🛠️ 工具管理模块 (Prop Management)**
  * 集中管理各类加密工具与方案，完整记录工具编号、加密方式、链接及加密强度。

* **🛡️ 主动防御与黑名单机制 (Active Defense & Blacklist)**
  * 前后端查询接口内置防护规则，实时检测输入内容是否包含 `select`、`union`、`<?php` 等注入攻击特征。
  * 触发恶意特征的请求将被立即拦截，系统自动将该用户 ID 存入 `blacklist` 黑名单表，并强制退回登录界面警告“非法攻击”。
  * 登录流程自动校验黑名单状态，被封禁账号无法再次登录系统。
  * 系统主界面底部设有显眼的白色加粗防御警示语，提醒用户切勿尝试非法攻击。

* **📜 登录审计与记录 (Login Audit)**
  * 完整的登录状态追踪，每次登录均在 `record` 表自动写入记录编号、用户编号、登录时间及状态。
  * 状态精确细分为 `permit` (允许)、`refuse` (拒绝) 和 `ban` (禁止)。
  * 首页提供针对登录记录的自定义筛选展示，支持输入指定时间与登录状态进行精准查询。

## 🛠️ 技术栈与系统架构

### 核心技术
* **后端框架**：Spring Boot 2.7.17 构建核心服务层，遵循标准 MVC 规范。
* **数据持久层**：集成 MyBatis-Plus 与 MyBatis 实现 ORM 映射，提升数据操作效率。
* **前端框架**：Vue 3 结合 Element Plus 组件库构建响应式用户界面。
* **路由与通信**：通过 Vue Router 进行页面导航与路由拦截，采用 Axios 处理前后端统一 HTTP 请求。
* **数据库**：关系型数据库 MySQL 负责核心业务数据的事务管理与持久化存储。

### 三层架构设计
* **Controller 层**：接收前端 POST 等 HTTP 请求，提取参数并封装返回结果。
* **Service 层**：承载业务逻辑与数据验证，协调多层 Mapper 操作并处理事务。
* **Mapper 层**：直接对接底层 MySQL 数据库执行 SQL 语句，并返回操作结果。

## 📂 核心数据库表结构

系统基于 6 张核心基本表构建，并依靠主外码保持强数据完整性与映射关联：

* **`user` (用户基本表)**：存储用户信息，包含用户编号、用户名、用户密码、手机号等属性。
* **`sensor` (密码信息表)**：托管用户存入的密码凭证信息，包含密码编号、用户名、密码、安全级别、日期与备注属性。
* **`prop` (工具表)**：管理工具及加密属性，包含工具编号、加密方式、链接、加密强度属性。
* **`user_sensor` (用户密码关联表)**：处理用户与托管密码凭证之间的多对多映射关系。
* **`record` (登录记录表)**：支撑登录审计追踪功能，存放每个用户每次登录的记录编号、用户编号、登录时间及状态信息。
* **`blacklist` (黑名单表)**：存放触发主动防御系统判定的用户编号及黑名单编号。
