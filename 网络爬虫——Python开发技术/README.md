# Python 网络爬虫大作业

一个功能完善的网络爬虫项目，支持从目标网站自动爬取文章/章节内容，并保存为 Word 文档。项目提供了命令行和图形界面两种使用方式，支持全量爬取和增量更新两种模式。

## 功能特性

### 核心功能
- ✅ **通用网站爬取**：支持爬取任意静态 HTML 网站的文章/章节内容
- ✅ **全量爬取模式**：第一次使用，从起始网址批量获取站内所有文章
- ✅ **增量更新模式**：之后使用，只检查并下载新增的文章/章节
- ✅ **智能章节合并**：自动识别章节分页，将同一章节的多页内容合并为完整文档
- ✅ **章节标题过滤**：可选择只爬取符合小说章节格式标题的文章（如"第1章"、"第一章"、"001章"等）
- ✅ **链接去重**：自动记录已爬取链接，避免重复下载
- ✅ **分类保存**：支持按文件夹分类保存，可选择已有文件夹或新建文件夹
- ✅ **分段优化**：自动处理文章段落，生成格式清晰的 Word 文档
- ✅ **图形界面**：提供友好的 Tkinter GUI 界面，操作简便
- ✅ **停止功能**：支持随时停止正在进行的爬取任务

## 使用方法

### 方式一：图形界面（推荐）

1. **启动 GUI 程序**：

```bash
python gui_app.py
```

2. **主界面操作**：
   - 点击"全量爬取（第一次爬取）"进入全量爬取界面
   - 点击"增量爬取（之后只爬新章节）"进入增量更新界面

3. **全量爬取**：
   - 输入起始网址（例如小说目录页或网站首页）
   - 设置最多爬取页面数（建议 50~500）
   - 可选：勾选"只爬取小说章节标题文章"
   - 选择保存位置：使用已有文件夹 或 新建文件夹
   - 点击"开始全量爬取"按钮
   - 可在日志窗口查看实时进度
   - 需要时点击"停止爬取"按钮中断任务

4. **增量爬取**：
   - 输入与第一次全量爬取相同的起始网址
   - 设置本次最多检查页面数（建议 30~200）
   - 选择是否只爬取章节标题文章
   - 选择保存位置（可点击"刷新"按钮更新文件夹列表）
   - 点击"开始增量爬取"按钮

### 方式二：命令行

#### 全量爬取

```bash
python crawler_full.py
```

按提示依次输入：
- 起始网址
- 最多爬取页面数（留空默认 100）
- 是否只爬取章节标题文章（输入 y 或直接回车）
- 保存文件夹名称

#### 增量更新

```bash
python crawler_update.py
```

按提示依次输入：
- 起始网址
- 本次最多检查页面数（留空默认 80）
- 是否只爬取章节标题文章
- 保存文件夹名称

## 配置说明

如需更换爬取的目标网站，可编辑 `config.py` 文件：

```python
# 目标网站基础 URL
BASE_URL = "https://your-target-website.com"

# 其他参数根据实际网站结构调整
```

### 修改保存路径

在 `config.py` 中修改：

```python
# 文章保存目录
ARTICLE_DIR = os.path.join(BASE_DIR, "文章")  # 可改为其他目录名
```

## 注意事项

### 1. 网站类型
- ✅ **推荐**：静态 HTML 网站（文章内容在页面源代码中可见）
- ❌ **不推荐**：动态渲染网站（需要 JavaScript 执行才能显示内容）

### 2. 检查网站是否适合爬取
在浏览器中打开目标文章页面，右键选择"查看页面源代码"（View Page Source），如果能直接在源码中找到正文内容，说明适合使用本爬虫。

### 3. 爬取速度
- 程序已内置延迟机制（每篇文章间隔 0.5 秒），避免请求过快
- 建议不要设置过大的"最多页面数"，以免长时间占用资源

### 4. 章节分页支持
项目已针对常见的章节分页格式进行了适配（如 `.../123.html` → `.../123_2.html` → `.../123_3.html`），会自动合并同一章节的所有页面。

### 5. 文件夹管理
- 每次爬取建议使用不同的子文件夹名称，便于分类管理
- 可通过 GUI 界面的"刷新"按钮更新已有文件夹列表

## 常见问题

### Q: 爬取的文章只有标题没有内容？
**A:** 可能是目标网站的正文使用了动态加载，或者正文区域的 HTML 结构与程序中的选择器不匹配。可以：
1. 检查目标网站是否为静态 HTML
2. 查看 `utils_crawler.py` 中的正文选择器，根据实际网站结构调整

### Q: 提示"下载失败"或"访问失败"？
**A:** 可能的原因：
- 网络连接问题
- 目标网站暂时无法访问
- 链接格式不符合预期

程序会自动跳过失败的页面，继续爬取其他页面。

### Q: 如何爬取特定网站的所有章节？
**A:** 
1. 找到该网站的章节目录页（通常是一个列表页面，包含所有章节的链接）
2. 将这个目录页的 URL 作为"起始网址"输入
3. 设置较大的"最多页面数"（如 500）
4. 勾选"只爬取小说章节标题文章"以过滤非章节页面

### Q: 增量爬取没有发现新文章？
**A:** 
- 检查是否在同一个起始网址下运行
- 确认目标网站确实有新文章更新
- 查看 `links.txt` 文件，确认链接记录是否正确

## 技术实现

### 核心库
- **requests**：发送 HTTP 请求
- **beautifulsoup4**：解析 HTML 内容
- **python-docx**：生成 Word 文档
- **lxml**：HTML 解析器
- **tkinter**：图形界面（Python 内置）

### 主要算法
- **广度优先搜索（BFS）**：从起始网址开始，遍历网站内所有相关页面
- **链接去重**：使用 `links.txt` 文件记录已处理链接，避免重复
- **章节分页合并**：自动识别分页格式，合并同一章节的多页内容
