# 🌐 信息中心网络的设计与实现 (Design and Implementation of Information Center Network)

> **课程名称**：专业综合课程设计二（网络类） / 计算机网络课程设计
> **开发环境**：装有 windows 操作系统的计算机结合 Cisco Packet Tracer 仿真软件  

---

## 📖 项目简介
本项目面向包含 1 个网络中心及 2 个系的中小型校园网络设计并实现互联架构。网络总用户规模预计 200-300 人，物理位置分布于 3 栋楼宇。设计旨在解决校园网中部门间访问隔离不足、IP 地址管理混乱及服务器服务可用性低等实际问题。通过构建独立子网并以路由器互连，实现广播域隔离与流量管控，同时统一部署基础网络服务以保障各类应用资源的便捷访问。

---

## 🔀 网络拓扑结构与 IP 规划

系统采用星型拓扑结构设计。以网络中心的 `2960-24TT` 交换机为核心汇聚各类服务资源，通过 `1841` 路由器互连 A系与 B系的接入交换机及普通用户 PC。全网划分为三个相互隔离的独立子网，统一通过路由器实现互通：

* **网络中心子网**：使用静态 IP 地址以保障服务稳定性。网段规划为 `192.168.100.0/26`。
* **A系子网**：普通用户经由 DHCP 动态获取 IP 地址。网段规划为 `192.168.110.0/24`。
* **B系子网**：普通用户同样采用 DHCP 动态获取所在子网的 IP 地址。网段规划为 `192.168.120.0/24`。

## ✨ 核心服务与功能部署

网络中心共集中部署了 5 台提供核心业务的服务器，各服务器的具体配置与实现功能如下：

* **DHCP 服务 (IP: `192.168.100.3`)**
  * 自动为跨网段的普通用户 PC 动态分配 IP 地址、子网掩码、默认网关及 DNS 参数。
  * 路由器接口配置了 `ip helper-address 192.168.100.3` 中继代理命令，以支持将本地广播数据包转发至不同网段的 DHCP 服务器。
* **DNS 服务 (IP: `192.168.100.2`)**
  * 提供域名解析服务，将易记的域名转换为对应的 IP 地址。
  * 记录并添加了正向解析映射，使用户可通过易记域名直接访问 Web 与 FTP 服务器资源。
* **Web 服务 (IP: `192.168.100.4`)**
  * 绑定域名 `www.web.com`，借助 HTTP 协议向客户端提供在线信息展示。
  * 采用默认首页 `index.html` 进行页面布局设计与内容渲染展示。
* **FTP 服务 (IP: `192.168.100.5`)**
  * 绑定域名 `ftp.ftptest.com`，通过 FTP 协议支持跨设备的文件共享、上传与下载传输。
  * 启用了用户身份认证机制，支持精细化配置不同用户的读取、写入、删除及重命名等操作权限。
* **Email 服务 (IP: `192.168.100.6`)**
  * 配置本地域名 `email.com`，承担校园网内电子邮件的接收与存储转发任务。
  * 邮件发送逻辑基于 SMTP 协议构建，邮件接收逻辑基于 POP3 协议构建。
  * 预设独立账户支持不同局域网主机之间顺畅收发电子邮件。
* **路由协议配置**
  * 路由器全局启用了 RIP 动态路由协议进程。
  * 规范配置接口的子网掩码及 MAC 地址等参数，实现跨网段数据包的精确寻址与下一跳路由转发。

## 🚀 系统测试与验证

通过 Cisco Packet Tracer 虚拟仿真终端完成全方位系统测试，均达到预期设计要求：

* **动态获址验证**：PC 开启 DHCP 模式后，能成功从对应网段的地址池自动获取 IP、掩码及网关配置。
* **域名连通测试**：PC 浏览器输入 `www.web.com` 顺利加载展示 `index.html` 网页；通过终端执行 `ftp ftp.ftptest.com` 命令能成功完成身份验证并列出远程目录资源。
* **邮件收发联通**：登录不同的独立测试账户，可实现可靠的跨网段端到端邮件撰写、发送与收取。
* **全网互通性**：通过 `ping` 命令检验任意 PC 终端与网络中心核心服务器之间的连通性，数据包收发稳定且具备良好的时延表现。
