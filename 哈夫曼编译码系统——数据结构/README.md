# 🌳 哈夫曼编/译码系统的设计与实现 (Huffman Coding & Decoding System)

> **项目类型**：数据结构课程设计  
> **核心数据结构**：树型结构（哈夫曼树）、顺序表（静态链表存储）、动态指针数组  
> **编程语言**：C++ (兼容 C 语言标准)

---

## 📖 项目简介
本项目是一个基于字符信源频度构建的哈夫曼（Huffman）编/译码控制台系统。利用哈夫曼编码进行通信可以大幅提高信道利用率、缩短传输时间并降低传输成本。本系统完整实现了从原始字符集与权值接收、哈夫曼树构建、自底向上生成前缀编码，到任意字符串的哈夫曼编码转换以及基于 0/1 代码串的自顶向下高效译码全套闭环功能。

---

## ✨ 核心功能模块

系统提供友好的控制台交互目录，支持重复选择和操作以下功能：

* **1. 输入数据并建立哈夫曼树 (Input data and establish HuffmanTree)**
  * 动态输入待处理的叶子结点个数 $n$。
  * 依次录入各个字符及其对应的权重（频度）信息。
  * 核心算法内部循环选取当前无双亲结点中权值最小的两个结点合并，生成 $2n-1$ 个结点的完整哈夫曼树。
* **2. 查看哈夫曼树结点信息 (View node information of the HuffmanTree)**
  * 打印底层结构数组中所有结点的详细属性，直观呈现静态链表内部的 `data`、`weight`、`parent`、`lchild` 与 `rchild` 关系，便于调试与结构核验。
* **3. 生成哈夫曼编码表 (Encoding for generating HuffmanTree)**
  * 自底向上（从叶子结点溯源至根结点）逐位识别路径。
  * 采用**自字符串末尾向前写入**的技巧，完美纠正逆向读取顺序，生成正确的 0/1 前缀编码串，并打印字符对应关系表。
* **4. 字符串编码转换 (Input string generating encoding)**
  * 接收用户输入的任意明文字符串，查表将其转换为紧凑的 0/1 哈夫曼二进制密文输出。
* **5. 二进制密文译码 (Input encoding generating decoding)**
  * 接收 0/1 代码串，直接利用已建成的哈夫曼树，从根结点出发进行自顶向下识别（遇 `0` 进左子树，遇 `1` 进右子树）。
  * 触达叶子结点即输出对应字符并自动复位指针到树根，工作量小且运行效率极高。

## 🛠️ 数据结构与存储设计

* **哈夫曼树存储 (`HuffNode`)**：采用顺序表（一维结构体数组）存储。通过动态分配 $2n$ 个连续空间，利用数组下标充当静态指针，维护父子关系。
  ```cpp
  typedef struct {
      char data;                  // 字符信息
      unsigned int weight;        // 权值/频度
      unsigned int parent, lchild, rchild; // 双亲及左右孩子伪指针（数组下标）
  } HuffNode, *HuffmanTree;
