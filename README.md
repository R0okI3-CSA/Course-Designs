## ✨ 核心技术与工程亮点 (Engineering Highlights)

在开发这些系统时，我着重将理论知识转化为解决复杂工程问题的能力，并在全子项目中贯彻了以下技术亮点：

### 🛠️ 1. 全栈架构与分层设计
* 在**房屋租赁管理系统**中，采用现代化的前后端分离架构（Spring Boot + Vue 3 + Element Plus），遵循标准 `Controller-Service-Mapper` 三层思想，保障了系统的高响应度与良好的前后端解耦。

### 🔒 2. 并发控制与 ACID 事务安全
* 在**高校图书馆借阅系统**的数据层设计中，为解决高频并发下的“一册多借”、“逾期未罚”等问题，严格部署了行级悲观锁 (`SELECT ... FOR UPDATE`)，确保借还书与缴费业务的一致性与并发安全。

### 🛡️ 3. 主动防御与网络安全意识
* 全栈项目接口层均内置敏感字符过滤与防 SQL 注入拦截机制；通过设立独立的 `blacklist`（黑名单表）自动封禁恶意试探账号。
* 在**计算机网络设计**中，利用 ACL 访问控制策略与 VLAN 广播域划分，实现了物理楼宇与核心部门之间的强逻辑隔离。

### 🧠 4. 底层算法优化
* 在**哈夫曼编译码系统**中，避免了低效的密文全量轮询，直接依靠构建的树型结构指针进行密文流的自顶向下精准寻路，大幅降低了时间复杂度。
