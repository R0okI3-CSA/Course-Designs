# 🏦 银行账户管理系统 (Bank Account Management System)

> **项目类型**：C++ 面向对象编程课程设计  
> **核心特性**：面向对象封装、控制台交互、异常处理安全机制  

---

## 📖 项目简介
本项目是一个基于 C++ 开发的控制台银行账户管理系统。系统通过构建独立的 `Card`（银行卡/账户）类，完整实现了账户生命周期管理（开户、查询、存取款、密码重置与销户）。项目着重演示了面向对象编程中的**数据封装**与**访问控制**，并结合 `try-catch` 异常处理机制实现了密码试错锁定功能，保障账户基本安全。

---

## ✨ 核心功能模块

系统提供标准控制台菜单交互，包含以下核心功能：

* **1. 开户 (Open an account)**
  * 按顺序自动分配唯一账户 ID（从 `202401` 起始，预设上限 5 个账户）。
  * 支持用户录入姓名并设置 6 位初始密码。
* **2. 账户查询 (Account inquiry)**
  * 经密码验证后，展示当前账户的详细信息（ID、持卡人姓名、账户余额）。
* **3. 存款 (Deposit)**
  * 经密码验证后，输入存款金额，实时更新账户余额。
* **4. 取款 (Withdraw)**
  * 具备防透支校验机制：若取款金额超出当前余额，系统自动拦截并提示错误。
* **5. 重置密码 (Reset password)**
  * 提供快捷的账户密码修改接口。
* **6. 销户 (Logout)**
  * 验证密码后，将账户持卡人置为 `NULL`，清空余额，并将账户状态标记为注销（不可再访问）。
* **🔒 安全验证机制 (Password Monitor)**
  * 独立的鉴权模块。输入密码时提供 **3 次** 试错机会。
  * 若 3 次输入均错误，系统触发异常处理机制，自动将账户锁定（锁定后需联系工作人员）。

## 🛠️ 系统设计与技术亮点

### 核心类设计 (`Card`)
私有成员变量严格封装数据，仅通过公有成员函数对外提供操作接口：
* `id`：账户唯一编号
* `name`：持卡人姓名
* `code`：账户密码（兼顾状态标识功能：`0` 表示已锁定，`-1` 表示不存在/已销户）
* `money`：账户余额

### 技术栈
* **编程语言**：C++ (标准 ISO C++)
* **关键技术点**：
  * **OOP 封装**：私有属性与公有方法的合理划分。
  * **构造函数初始化列表**：使用 `Card::Card(...) : id(x), name(y)...` 规范初始化对象。
  * **异常处理**：在 `monitor()` 鉴权函数中运用 `try-catch` 捕获密码输入超限错误。
  * **状态机思维**：利用 `code` 变量的不同特殊数值区分账户的正常、锁定与注销状态。

## 📦 环境准备与运行指南

### 1. 开发与运行环境
* 任何支持 C++98 及以上标准的编译器（如 GCC/g++、Clang、MSVC）。
* 推荐 IDE：VS Code、Dev-C++、CLion 或 Visual Studio。

### 2. 编译与运行
在命令行终端中进入源文件所在目录，执行以下命令进行编译和运行：

```bash
# 1. 编译源代码
g++ -o BankSystem 银行账户管理系统.cpp

# 2. 运行程序
# Windows 环境:
.\BankSystem.exe
# Linux/macOS 环境:
./BankSystem
